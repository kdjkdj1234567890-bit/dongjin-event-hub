# 이벤트 허브

공모전·체험단·이벤트 응모 원장을 브라우저에서 바로 보는 정적 페이지입니다.

- `index.html` — 화면(요약 KPI, URL/제목 중복 체커, 상태·카테고리 필터, 검색)
- `data/ledger.json` — 전체 원장(공개용으로 전화번호·주소·계정·실명을 마스킹)
- `data/index.json` — 중복 체크용 경량 인덱스
- `build_data.py`, `sanitize.py` — 시트 CSV에서 데이터를 만들고 개인정보를 마스킹하는 스크립트

개인정보는 배포 전 `sanitize.py`로 마스킹합니다(`[연락처]`, `[주소]`, `[아이디]`, `[이메일]`, `본인`).
